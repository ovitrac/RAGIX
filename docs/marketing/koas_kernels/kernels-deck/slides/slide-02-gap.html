The gap

What is missing between a capable model and a trustworthy result

A coding-capable model can plan, call tools and write. What it cannot do on its own is compute exactly, reproduce a result, and prove how it was obtained, on material larger than its context.
Models are fluent, not exact
  • A number written by a model can drift between runs
  • A corpus does not fit in a context window
  • Nothing records why an answer is what it is
Tools are atomic
  • A function call does one thing
  • It declares no dependency on other tools
  • It returns a value, not a provenance
Pipelines are hand-written
  • Every new combination of tools is new glue code
  • The model re-plans each step in prose
  • Sensitive data travels through the prompt
