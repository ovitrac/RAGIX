The problem
  • Most pipelines flatten documents into strips of text: a table loses its rows and columns, a heading its place, a citation shrinks to a file name.
  • Layout models recover part of that structure by prediction. A prediction can be wrong without saying so.
  • The same file can read differently after a model or library update.
Four principles, each checked by the tests
  • Object before fragment: one typed tree per document, the same vocabulary for every format.
  • An exact citation on every node: page and position, sheet and cell, slide and shape, line; plus the reader's version.
  • Abstain rather than guess: undecided cases are recorded with place, reason and signals.
  • Reproducible by construction: canonical JSON, same files, same trees, same root hash.
Where exactly does this statement come from? Do I get the same reading tomorrow, on another machine? Saqqara records the answer to both with the reading itself.
