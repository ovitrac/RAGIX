Four doors, one answer, and the families above
  • MCP: four tools, koas_saqqara_run, _status, _index, _search.
  • Command line: saqqaractl run | status | index | search, each with --json; the same hits as MCP, checked by a test.
  • Python: SaqqaraKernel().run(...) returns the envelope of every RAGIX kernel.
  • The orchestrator: ragix-koas chains Saqqara with the other families.
  • Built on it: the tender family probes the store Saqqara builds; the harvest library reports over its readings.
Chained by what they declare. The registry resolves a requirement by kernel name, then by a capability exactly one kernel provides; two providers is an error, never a silent choice. Every run records which kernel served it.
