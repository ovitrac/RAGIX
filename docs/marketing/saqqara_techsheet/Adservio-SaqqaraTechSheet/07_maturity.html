7. Maturity, openness & stack

Saqqara ships inside RAGIX 0.74 and is described here at commit b7eb0a7. It is open source under the MIT licence, published on GitHub with its specification, its tests and its documentation, so its behaviour can be checked line by line rather than taken on trust. Its maturity is stated layer by layer, against the specification.

7.1 What Saqqara does not do yet

The user documentation lists its limits rather than leaving them to be found. The main ones:

  • PDF text carries a placement point, not a bounding box, and one printed line can become several nodes.
  • Without the opt-in outline analyzer, heading nodes come only from a PDF's declared outline: a PDF without one, and every Word and PowerPoint file, gets no heading nodes.
  • A standard run produces no figures, captions or drawn regions; these analyzers are used as a library.
  • A standard run builds no table nodes from a PDF; PDF tables come from the Explorer through the opt-in PyMuPDF reader. Markdown pipe tables are kept as raw text.
  • There is no OCR: scanned pages are reported as unread, never as empty.
  • A spreadsheet image that the Excel library cannot decode is neither read nor counted (known gap H1).
  • Text drawn inside a PDF form object, such as the running header of a browser-printed page, is read twice and partly misplaced (known gap H2).

7.2 A sovereign, open stack

Every component can run inside a private perimeter, on ordinary hardware, with no external service. The default install carries MIT, BSD and Apache licences only; the components under other terms are optional and named.

Default install
Python; pypdf (BSD-3-Clause); pypdfium2 (Apache-2.0 / BSD-3-Clause); python-docx, python-pptx, openpyxl (MIT); odfpy (offered under Apache-2.0); numpy (BSD); SQLite with FTS5.
Optional, by name
PyMuPDF (AGPL-3.0 or commercial) as an alternative reader and renderer; an embedding model through sentence-transformers or Ollama; LibreOffice, as an external program, for legacy .doc and .xls only.

7.3 In summary

Saqqara gives RAGIX, and every product built on it, one way to read documents: exactly, with a citation on every node, by tested rules that abstain when they cannot decide, without any language model, and with two hashes that make a reading replayable and checkable. It is open source, specified and tested, and its limits are published.

Exact
Page, cell, paragraph, slide or line on every node, and the version of the code that read it.
Honest
Refusals, abstentions and drops are counted and returned with the reading.
Sovereign
No model to host, no network call by default, permissive licences in the default install.
Integrated
Six RAGIX kernels, four interfaces, and the tender and harvest families built on top.
