5. Saqqara and Docling

Docling, started at IBM Research Zurich and now hosted by the LF AI & Data Foundation, is the best-known open-source document converter for generative AI. Docling and Saqqara answer the same question, how to turn documents into material a retrieval system can use, from opposite directions. Docling predicts the layout of each page and the structure of each table with trained vision models. Saqqara reads what the file itself records and recognises structure with written rules. Both run locally and both are MIT-licensed.

The table compares them on the points that matter to a reader who must cite and replay. Saqqara's column comes from its code and specification at commit b7eb0a7; Docling's from its public documentation and technical report, at version 2.150.1.

5.1 Measured side by side

Both tools read the same public files twice on one ARM64 machine, CPU only. Docling read each file in its own process; Saqqara read all files in one process, and its memory was measured in a separate run per file. Docling 2.150.1 ran its standard PDF pipeline with OCR off, TableFormer in its default accurate mode and 4 threads. Saqqara ran at commit b7eb0a7: a standard run with its default reader, plus the Explorer's digest for PDF tables. The two PDFs below are the RAGIX tech sheet (19 pages) and a 38-page guide to sovereign LLM operations, both published in the RAGIX repository.

What the rows do not say. The two tools do not produce the same objects. A Saqqara paragraph is one run of text as the file draws it; a Docling item is a region its layout model found on the rendered page. Saqqara's PDF tables are PyMuPDF's observations of the grids drawn in the file, with a box for every cell; Docling's are TableFormer's predictions inside the table regions it detected. No table from either tool has been checked against the pages by eye, so a higher count is not shown to be a better reading. The machine was shared with other jobs, so the times compare with each other, not with another machine. Docling's speed here, 1.45–1.92 pages per second, lies within the 0.60–2.18 that its technical report gives at 4 threads with OCR off (arXiv:2408.09869).

More threads. In Docling’s technical report, 16 threads were faster than 4. Here, at 20 threads, Docling was slower (1.77–1.84 and 3.78–4.01 seconds per page); the cause was not diagnosed. Its two exports then differed for every PDF, from each other and from the 4-thread export: only box coordinates moved, by at most 0.000412 pt (those of pictures and tables, and in one comparison nine of text boxes), and every count stayed equal. Saqqara's roots were also equal across two architectures.

Pages without text, and Markdown. On a 14-page slide export that has no text layer, neither tool reads text without OCR: Saqqara records one abstention per page, and its library's figure pass finds the 14 pictures; Docling reports 27 pictures and four tables with no rows, and grades the pages “fair”. On two Markdown files, Docling types the pipe tables (1 and 32) and the code blocks, which Saqqara's Markdown reader keeps as paragraphs; Docling's Markdown items carried no location (0 of 149 and 0 of 1 750), while each Saqqara heading and paragraph cites its line. 5.2 When to use which

Docling is the better fit when…
pages are scanned or photographed; the corpus includes HTML, EPUB, images or audio; reading order must be recovered from complex visual layouts; and the goal is clean Markdown or JSON for a retrieval framework it already plugs into.
Saqqara is the better fit when…
every statement must be cited to its page, cell or line; uncertain structure must be flagged rather than predicted; a reading must be replayable and its hash checked later; spreadsheets matter cell by cell; and no model may be hosted or updated.

5.3 Using both

The two are complementary rather than exclusive. A page that Saqqara records as unread, because it has no text layer, is exactly the page an OCR pipeline such as Docling's can read. A deployment can route those pages to Docling and keep Saqqara for everything with a text layer, provided each reading keeps the citation of the tool that produced it. RAGIX does not wire Docling in today; this is a pattern, not a feature.

THE ONE-LINE MESSAGE

Docling is built to see a page the way a person does; Saqqara is built to state, exactly and repeatably, what a file records, and to say so when it cannot decide.
