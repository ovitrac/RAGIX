6. Proof — measured on public documents

Every figure in this section was measured on files published in the RAGIX repository, so anyone can repeat it: the RAGIX tech sheet (PDF, 19 pages), its slide deck exported to PDF (14 pages with no text layer), a 38-page guide to sovereign LLM operations, the Saqqara README and the Saqqara user reference (Markdown). Each file was read twice, on an x86-64 laptop and on an ARM64 workstation, with the reader code of commit b7eb0a7.

6.1 Same bytes, same reading

  • Run after run. Each file read twice gave the same merkle_root over its trees and the same source_root over its bytes, file by file and for the whole set. The command line gave the same root as the kernel called from Python.
  • Machine after machine. With the same code and the same bytes, an x86-64 laptop and an ARM64 workstation agreed on every root, node count, table, abstention, drawn region, caption binding, index count and search hit, rank included. Only the names of the working folders differed. This held before the fix of section 6.4 and after it.
  • Library version. Moving the opt-in PyMuPDF reader from 1.28.0 to 1.27.2.2 changed the reader version recorded in each tree, which the root follows, and moved 10 of 14 214 text anchors of the operations guide by about 2 pt. Nothing else changed, the Explorer's tables included.
  • What each root covers. The same bytes copied under another name gave the same source_root and, once the recorded path is set aside, the same tree, but a different merkle_root: a tree records where it was read from.

6.3 Abstain rather than guess

The first case below is part of every run; the other three come from analyzers used as a library.

  • No text layer. The 14 pages of the slide export carry pictures only. Saqqara records one no-text-layer abstention per page, with the signals it read, and invents no text.
  • Captions. Of the 4 pictures of the tech sheet, the caption pass binds 1 and abstains on 3, each with its reason, no-candidate-within-gap.
  • Drawn regions. On the tech sheet, 1 818 drawing marks form 82 clusters: 58 become regions, 24 are refused (17 with too few operators, 7 too small) and 225 marks are set aside as page furniture. On the operations guide, every one of the 38 clusters spans its page and is refused as region-spans-page.
  • Headings by size. The operations guide declares its own outline, so the size pass abstains as declared-outline and records the 77 lines it would have promoted.

6.4 Found and fixed while measuring

A DEFECT FOUND BY THIS SHEET’S OWN MEASUREMENTS

The first measurements showed that the default PDF reader placed text where the text matrix alone puts it, without the page transformation: on the two browser-printed PDFs, 650 of 874 and 13 068 of 14 701 text anchors lay outside their page. A new proposition, K2.26, now states where a run of text starts, and a test that scales and flips a page holds the reader to it. After the fix (RAGIX pull request #42): 0 of 874, and 76 of 14 701. The 76 are the running header and footer, drawn inside form objects; that remaining case is published in the specification as the known gap H2. Re-measured, only text coordinates moved, with what the size pass derives from them: the headings it promotes on the tech sheet (73 to 66) and, on the operations guide where it abstains, the 77 lines it would have promoted (0 before). Sections, abstentions, caption binding, tables, index counts and search results stayed the same, on both machines.

6.5 The test suite

At commit b7eb0a7, the Saqqara tests give 1 850 passed, 9 skipped and 1 expected failure; two of the passing tests are the fix’s own. The skips are three live embedding tests that need a running model server, fixtures that pin an abstention rather than a split, refusals asserted elsewhere, and a check that needs the repository’s hooks. The expected failure states a defect measured on the frozen reader, so the suite cannot pass silently once it is fixed.

6.6 What these measurements do not show

  • No table, from Saqqara or from Docling, has been checked against the pages by eye: the counts are observations, not a score.
  • The Word, Excel and PowerPoint readers are covered here by the test suite only. The repository holds no public Office file, and the public samples for this sheet are still to be chosen.
  • The machines were shared with other work. The times in section 5.1 compare with each other; they are not a benchmark.
  • There is no OCR. Text inside PDF form objects (H2) and undecodable spreadsheet images (H1) remain open, and are published as such.
